# Upper bounds are deliberate. Peter's Mac installs these once and keeps
# them; GitHub Actions reinstalls from scratch on every run. With bare
# `>=` the two silently drift apart over months until a major release
# changes an API and only the cloud half breaks — at 3am, with no one
# watching. Capping below the next major keeps both sides on the same
# generation while still picking up patch and minor fixes.
#
# Versions verified working together on 2026-07-28 are noted alongside.
# To move to a new major: raise the cap, run `python3 -m unittest
# discover -s tests -t .`, then run local_sync.py once by hand.
